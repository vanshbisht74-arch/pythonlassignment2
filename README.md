# GradeBook Analyzer

A Python-based CLI tool for analysing and reporting student grades.

---

## 📘 Project Overview
Lecturers often need a fast and accurate way to compute statistics on student marks.  
Instead of manually performing calculations (average, grade assignment, distribution),  
the *GradeBook Analyzer* automates the entire process using a Python CLI program.

The tool can:
- Read marks from *manual input* or a *CSV file*
- Calculate statistics (mean, median, min, max)
- Assign grades (A–F)
- Display summary and formatted tables
- Filter pass/fail students
- Repeat analysis using a menu-based CLI loop
